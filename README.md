# Проект: Поиск и управление вакансиями с hh.ru

# Описание

Этот проект позволяет получать вакансии с сайта hh.ru через API, сохранять их в JSON-файл, а также удобно работать с ними через консольный интерфейс.

Основные возможности:

- Поиск вакансий по ключевому слову через API hh.ru

- Сохранение вакансий в JSON-файл без дублирования

- Чтение, удаление вакансий из файла

- Удобный консольный интерфейс для взаимодействия с пользователем

- Валидация и сравнение вакансий по зарплате

- Покрытие кода тестами >70%

# Структура проекта

```
project_root/
│
├── src/
│   ├── api/               # Работа с API hh.ru и абстрактные классы
│   ├── files/             # Работа с файлами (JSON и абстрактные классы)
│   ├── models/            # Класс Vacancy и другие модели
│   └── utils.py           # Вспомогательные функции
│
├── data/                  # Папка с файлом vacancies.json
│
├── tests/                 # Тесты для разных модулей
│
├── main.py                # Запуск консольного интерфейса
├── requirements.txt       # Зависимости проекта
└── README.md              # Этот файл
```

# Установка

1. Клонируйте репозиторий

```
git clone <URL_репозитория>
cd <папка_проекта>
```
2. Создайте и активируйте виртуальное окружение:

```
python -m venv .venv
# Windows
.\.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate
```
3. Установите зависимости:

```
pip install -r requirements.txt
```
# Использование

Запустите консольный интерфейс:

```
python main.py
```
Доступные действия:

- Поиск вакансий по ключевому слову
- Просмотр сохранённых вакансий
- Удаление вакансии по URL
- Выход из программы
